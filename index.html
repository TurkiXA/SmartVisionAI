نظرة عامة

ما هو النظام، ما الذي يقدمه، وكيف يختلف عن الحلول التجارية.

ما هو SmartVisionAI؟

SmartVisionAI هو نظام مراقبة ذكي محلي (On-Premise) يعمل على أجهزة Windows ذات المواصفات الضعيفة باستخدام المعالج فقط (CPU) دون الحاجة إلى كرت رسوميات. يستقبل بثاً من كاميرات IP عبر بروتوكول RTSP أو من تطبيقات الجوال عبر HTTP، ويشغّل نموذج YOLOv8n بصيغة ONNX لاكتشاف الأشخاص والسيارات، ثم يحفظ لقطة احترافية معلَّقة لكل حدث في قاعدة بيانات SQLite، ويولّد تقارير PDF بالعربية مع رسوم بيانية وإحصائيات مقارنة.

الطبقات الأربع

الاستقبال

كاميرات IP عبر RTSP، أو تطبيقات الجوال عبر HTTP، أو كاميرا ويب، أو ملف فيديو.

الذكاء الاصطناعي

YOLOv8n ONNX عبر ONNX Runtime مع تتبع خفيف (IoU Tracker) لمنع التكرار.

التخزين

SQLite للأحداث والمستخدمين، وملفات JPG/MP4 للوسائط، وPDF للتقارير.

العرض

واجهة ويب متجاوبة مع دعم العربية والإنجليزية، وبوتات تلجرام بأوامر فورية.

الهدف

ما الذي يهدف إليه المشروع وما القيم التي يقدمها.

المشاكل في الحلول الموجودة

تكلفة عالية

Hikvision وأمثالها تفرض رسوماً سنوية، وNest وRing تفرض اشتراكات شهرية للتصوير.

خصوصية مهددة

الفيديوهات تُرسَل لخوادم بعيدة، وقد تُستخدم في تدريب نماذج أو تُباع لجهات أخرى.

معقدة الإعداد

معظم الحلول تحتاج فنيين متخصصين، وتطبيقاتها صعبة الاستخدام.

قليلة التخصيص

لا يمكنك تعديل الواجهة، ولا إضافة بوت تلجرام، ولا إنشاء مستخدمين بصلاحيات مختلفة.

لماذا SmartVisionAI بديل أفضل

  1. مجاني بالكامل: لا اشتراكات، لا رسوم خفية، لا حاجة للاتصال بالإنترنت.
  2. خصوصية مطلقة: كل صورة تُحلَّل على جهازك، ولا تخرج أبداً.
  3. يعمل على أي جهاز: CPU فقط، بدون GPU.
  4. قابل للتعديل: مفتوح المصدر بالكامل، عدّل ما تشاء.
  5. دعم عربي حقيقي: واجهة وتقارير عربية (وليس مجرد ترجمة آلية).
  6. بوت تلجرام مدمج: تحكم من جوالك بدون فتح الموقع.
الفكرة الجوهرية: لا تحتاج شركة بمليون ريال لتراقب منزلك — يكفي جهاز كمبيوتر قديم يعمل بدون توقف، ونموذج YOLO صغير.

طريقة العمل

كيف يتحول الفيديو من الكاميرا إلى حدث محفوظ في قاعدة البيانات، خطوة بخطوة.

التدفق الكامل

1
الاتصال بالكاميرا

CameraWorker يفتح RTSP/HTTP/Webcam عبر OpenCV. عند الانقطاع، يعيد الاتصال تلقائياً بعد 5 ثوان (قابل للتعديل).

2
قراءة الإطارات

حلقة قراءة مستمرة تحفظ الإطار في الذاكرة (محمي بقفل) للبث المباشر، وتعيد استخدامه للكشف.

3
معالجة مسبقة + استدلال

كل inference_interval ثانية: تصغير الإطار إلى 416×416، تشغيل YOLOv8n، استخراج المربعات، فلترة الفئات المسموحة (شخص/سيارة)، ثم NMS لإزالة التداخلات.

4
التتبع ومنع التكرار

SimpleTracker يطابق كل كشف جديد مع مسار قائم بـ IoU. المسار الذي لا يُحدَّث لمدة tracker_max_age ثانية يُحذف. كل مسار يُحفظ مرة واحدة فقط.

5
إنشاء اللقطة الاحترافية

عند حدث جديد: annotate_snapshot يرسم شريطاً علوياً بالاسم والكاميرا والتاريخ، مربعات الكشف بزوايا بارزة، وتسميات بنسبة الثقة، وشريطاً سفلياً بالعدادات.

6
الحفظ في قاعدة البيانات

الصورة تُحفظ في database/users/{id}/imges/، ويُضاف صف في جدول events مع الطابع الزمني ونسبة الثقة ومسار الصورة.

7
العرض والإشعار

الواجهة تعرض الأحداث مباشرة (مع Pagination)، الرسوم البيانية تتحدث كل 30 ثانية، والبوت يرسل إشعاراً فورياً عند الطلب أو تلقائياً.

دورة حياة الحدث

لاحظ: النظام لا يحفظ إطاراً واحداً لكل شخص يراه — بل صورة واحدة فقط عند ظهور هدف جديد. إن بقي الشخص 30 ثانية أمام الكاميرا، ستُسجَّل صورة واحدة فقط. هذا يوفّر مساحة ضخمة على القرص.

بدائل رُفضت ولماذا

  • YOLOv5/v8m أو v8l: أدق لكن أبطأ 3-5× على CPU. v8n يكفي للمراقبة.
  • TensorFlow: أثقل وأبطأ من ONNX Runtime على CPU.
  • PyTorch: يحتاج 2GB+ في الذاكرة، ONNX أخف بكثير.
  • PostgreSQL: يحتاج خدمة خلفية دائمة. SQLite يعمل بدون أي خادم.
  • React/Vue: حزمة 200KB+ وحجم بناء كبير. HTML خام كفيل وأسرع.
  • Django: "batteries included" لكن يفرض بنية معقدة على تطبيق محلي.

التحويل إلى EXE

تحويل المشروع إلى تطبيق Windows مستقل بدون Python.

الخطوات

PowerShell
# 1. فعّل البيئة
cd C:\Users\turki\Desktop\SmartVisionAI
.\.venv\Scripts\Activate.ps1

# 2. ثبّت PyInstaller
pip install pyinstaller

# 3. تأكد من الخطوط
New-Item -ItemType Directory -Force -Path fonts
Copy-Item "C:\Windows\Fonts\arial.ttf"   "fonts\arial.ttf" -Force
Copy-Item "C:\Windows\Fonts\arialbd.ttf" "fonts\arialbd.ttf" -Force

# 4. البناء
pyinstaller SmartVisionAI.spec --clean --noconfirm

# 5. التشغيل
cd dist\SmartVisionAI
.\SmartVisionAI.exe

ما ينتج عن البناء

  • مجلد dist/SmartVisionAI/ هو التطبيق النهائي — انسخه كاملاً.
  • الحجم المتوقع: 400–600 ميجا.
  • لا يحتاج Python على الجهاز الهدف.
  • على الأجهزة الأخرى: ثبّت VC++ Redistributable أولاً.
تحذير: لا تنسخ SmartVisionAI.exe وحده — يحتاج مجلد _internal/ المجاور. انسخ المجلد كاملاً.

الأمان

كيف يحمي النظام بياناتك وبيانات المستخدمين.

  • تشفير كلمات المرور: PBKDF2-HMAC-SHA256 مع 200,000 تكرار وملح عشوائي — لا تُخزَّن كلمة المرور الأصلية أبداً.
  • جلسات آمنة: توكن عشوائي 32 بايت، كوكي httponly + samesite، انتهاء بعد 30 يوماً.
  • مفتاح سري: يُنشأ تلقائياً في .secret لتوقيع الجلسات.
  • مصادقة API: كل نقطة نهاية محمية بصلاحية محددة — لا وصول غير مصرح.
  • منع Path Traversal: التحقق من أن مسار الصورة داخل المجلدات المسموحة فقط.
  • إخفاء التوكنات: GET /api/config لا يعيد توكنات البوتات.
  • حماية آخر مدير: لا يمكن حذف آخر حساب admin نشط.
  • عزل البيانات: كل مستخدم يرى فقط بياناته — لا تسريب.
  • الخادم محلي: يعمل على 0.0.0.0:5000 افتراضياً — يمكن تقييده على 127.0.0.1 في app.py.

الأسئلة الشائعة

هل يعمل على جهاز ضعيف؟

نعم. النظام مصمم لأجهزة CPU فقط بدون GPU. الحد الأدنى المُختبر: 4GB RAM، معالج i3 جيل 8 أو أعلى. الأداء يُضبط من الإعدادات (دقة معالجة أصغر = سرعة أعلى).

هل يحتاج إنترنت؟

لا. يعمل بشكل كامل بدون إنترنت. الإنترنت مطلوب فقط في حالتين: تحميل المكتبات عند التثبيت (مرة واحدة)، وإرسال تقارير تلجرام.

كم عدد الكاميرات المدعومة؟

افتراضياً 3 كاميرات لكل مستخدم (قابل للتعديل في global_config.json). العملي: كاميرا واحدة لكل نواة CPU تقريباً.

هل يحفظ صورة لكل إطار؟

لا. بفضل Object Tracking، يُحفظ صورة واحدة فقط لكل حدث جديد. لو بقي الشخص 30 ثانية أمام الكاميرا، تُسجَّل صورة واحدة.

ما دقة كشف النظام؟

لا يوجد رقم ثابت "دقة" — يعتمد على: جودة الكاميرا، الإضاءة، زاوية التصوير، المسافة. النموذج (YOLOv8n) هو الأنسب لمراقبة قريبة ومتوسطة، وليس للتحليل من مسافات بعيدة جداً.

هل يدعم عدة مستخدمين؟

نعم. كل مستخدم له قاعدة بياناته وإعداداته وكاميراته. لا يرى المستخدم بيانات الآخرين. أول مستخدم يصبح admin تلقائياً، ويمكنه إنشاء مستخدمين آخرين بصلاحيات محددة.

هل يمكنني بيع هذا النظام؟

النظام مبني على مكتبات مفتوحة المصدر (Flask, OpenCV, YOLOv8). يمكنك استخدامه تجارياً مع مراعاة تراخيص كل مكتبة. أنصح بمراجعة تراخيص: Ultralytics YOLO (AGPL-3.0) لها قيود تجارية.

ما الفرق بينه وبين Hikvision/Nest؟

Hikvision/Nest: جاهز لكن مكلف، سحابي، محدود التخصيص. SmartVisionAI: مجاني، محلي، خصوصية كاملة، قابل للتعديل بالكامل، يعمل على أي جهاز، لكن يتطلب إعداداً يدوياً.
